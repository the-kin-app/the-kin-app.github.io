# Everything is crawlable on purpose. /qr/, /business/ and /survey/ are kept
# out of search with a `noindex` meta tag on the pages themselves, NOT with a
# Disallow here — a disallowed page is never fetched, so a crawler would
# never read the noindex and the URL can still surface as a bare link.
#
# AI crawlers are welcome too, training bots included: a pre-launch app wants
# to be known. They are named below so that stays explicit — each vendor runs
# separate bots for search, user fetches and training, and allowing one does
# not allow the others.
